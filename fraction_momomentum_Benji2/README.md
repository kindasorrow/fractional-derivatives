# Fractional Momentum in PyTorch

Исследование дробного momentum (порядка α) для оптимизации нейронных сетей.

## Идея
Классический momentum (в SGD/Adam) использует экспоненциальное затухание. Дробный momentum дает степенной хвост (веса Грюнвальда-Летникова). Мы сравниваем:
1. **Baseline:** SGD с momentum.
2. **Честный дробный:** Хранит N последних градиентов (медленно, много памяти).
3. **Быстрый:** Аппроксимирует хвост суммой K экспонент (K momentum-буферов с разными β).

## Структура проекта
* `data/` — данные (MNIST/CIFAR-10 скачиваются автоматически, в git не входят).
* `src/` — исходный код (оптимизаторы, модель, скрипты обучения).
* `notebooks/` — Jupyter ноутбуки с экспериментами.
* `results/` — графики и таблицы.
