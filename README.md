## 💡 Идея

Спектральная плотность мощности «цветного» шума:

$$S(f)\propto \frac{1}{f^{\beta}}$$

| β | Цвет шума | Звучит как |
|:---:|:---:|:---|
| **0** | ⚪ белый | ровное шипение |
| **1** | 🌸 розовый | шум дождя, водопада |
| **2** | 🟤 броуновский (красный) | низкий рокот прибоя |

> **Ключевой факт.** Дробный интеграл порядка $\gamma=\beta/2$, применённый к белому шуму,
> умножает *амплитудный* спектр на $f^{-\beta/2}$, а значит, *спектр мощности* — на $f^{-\beta}$.
> При $\gamma=1$ получается обычный интеграл (бегущая сумма), то есть броуновский шум.

## 🛠 Три метода

Все реализации лежат в [`src/pinknoise/generators.py`](src/pinknoise/generators.py) и имеют одинаковый интерфейс:
на входе белый шум, на выходе цветной.

### 1️⃣ FFT — `pink_fft`

Берём спектр белого шума, умножаем на $f^{-\beta/2}$, обнуляем нулевую частоту
(в нуле функция $f^{-x}$ бесконечна), делаем обратное БПФ.

$$X(f)\;\to\;X(f)\cdot f^{-\beta/2}$$

### 2️⃣ Грюнвальд–Летников — `pink_gl`

Дробный интеграл порядка $\gamma=\beta/2$ как свёртка с весами:

$$w_0=1,\qquad w_k=w_{k-1}\,\frac{k-1+\gamma}{k},\qquad x_n=\sum_{k=0}^{n} w_k\,\xi_{n-k}$$

Свёртка считается через `scipy.signal.fftconvolve`. Веса — коэффициенты ряда Тейлора
функции $(1-z)^{-\gamma}$ и убывают медленно: $w_k\sim k^{\gamma-1}$ («долгая память»).

### 3️⃣ Сумма экспонент (идея фильтра Келлетта) — `design_exp_bank`, `pink_exp`

Параллельно работают 5–7 фильтров первого порядка:

$$y_n = a_k\,y_{n-1} + b_k\,\xi_n,\qquad a_k=e^{-2\pi f_k/f_s}$$

* полюса $a_k$ расположены на **логарифмической** сетке частот $20\ldots 15000$ Гц;
* веса $b_k$ подобраны методом наименьших квадратов так, чтобы $|\sum_k H_k(f)|\approx f^{-\beta/2}$;
* применяются через `scipy.signal.lfilter`, результаты складываются.

Каждый фильтр даёт «излом» в спектре; сумма изломов на логарифмической сетке аппроксимирует прямую
в двойных логарифмических осях. Для сравнения в проекте есть классический **фильтр Келлетта**
(`pink_kellett`).
