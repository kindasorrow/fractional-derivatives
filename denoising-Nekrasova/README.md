# Шумодав
Код сравнивает классический **Perona-Malik** и дробную анизотропную диффузию с конечной маской **Грюнвальда-Летникова** на одном и том же шум, с независимым подбором числа итераций и kappa.
## Запуск
1. Скачать папку с прокетом
2. Распаковать архив
3. Распаковать data.zip, код в своей папке ищет папку data и берет данные из нее
4. Запустить main.py (python main.py)
## Как работает
1. Берет по 5 картинок из BSD500 & DTD
2. Добавляет **Гауссов** шум с заданным *sigma* и обрезает значения до допустимого диапазона `return np.clip(clean + noise, 0.0, 255.0).astype(np.float32)`
   - если пиксель стал меньше 0 -> ставится 0
   - если больше 255 -> ставится 255
3. Для каждой картинки:
   - перебирается сетка у  Perona-Malik и берет лучший по PSNR
   - для каждого alpha то же самое у дробного метода
4. Считает PSNR/SSIM, пишет metrics.csv, сравнения сохраняет в формате jpg и строит графики

# Классический **Perona-Malik**
См. статью Perona & Malik, 1990: *Scale-Space and Edge Detection Using Anisotropic Diffusion (IEEE TPAMI)*

Уравнение: 
du/dt = div( g(|∇u|) · ∇u )

с проводимостью: g(s) = 1 / (1 + (s / kappa)^2)

Малый градиент -> g ~ 1 (сглаживание), больлшой (край) -> g мало (край сохраняется)

дискретизация в коде опирается на <https://github.com/fubel/PeronaMalikDiffusion>

- 4 ортогональных направления с весом 1, 4  диагональных с весом 1/2
- для каждого направления: разность d= u_сосед - u    ; величина |d| (по RGB - корень из среднего квадрата), g(|d|)
- шаг: u←u+Δt∑factor⋅g⋅du←u+Δt∑factor⋅g⋅d, Δt=0.14
Т.е. не одна общая диверенция, а сумма направленных потоков, как в том репозитории

# Дробный метод 
## Веса Грюнвальда-Летникова
Классические коэффициенты GL порядка alpha:


```
c₀ = 1,
cₖ = cₖ₋₁ · (1 − (alpha+1)/k)    for k = 1, 2, …


Для 0 < alpha <= k, k>=1, cₖ <=0. Код берет положительные веса wₖ=-cₖ for k=1..K и нормирует ∑wₖ * k=1

## Дробный градиент и "дивергенция"

По оси x (аналогично y):
(G_x u)i=∑k=1Kwₖ(u_i−u_i−k)(G_x​u)i​=k=1∑K​wₖ​(u_i​−u_i−k​)

(gl_gradient, границы — replicate)

Проводимость — одна скалярная на пиксель из евклидовой нормы дробного градиента (усреднение по RGB):
g=1/(1+(∣∇^α u∣/κ))^2

Потоки f_x=g*G_x*u,  f_y=g*G_y*​u.

Оператор gl_adjoint — сопряжённая (в дискретном смысле) форма с shift_next, чтобы собрать дивергенцию. Обновление:
u←u−Δt (Adj_⁡xf_x+Adj⁡_yf_y),Δt=0.12
```
